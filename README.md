Stellarium 是一款免费开源的天象馆软件，可在您的计算机上运行。它以 3D 形式展示逼真的天空，
就如同您用肉眼、双筒望远镜或天文望远镜所看到的一样。

如果您是 Stellarium 的新用户，请访问 [www.stellarium.org](https://www.stellarium.org) 获取更多信息。
